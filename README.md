# Футбол — редактор учебной игры

Готовое браузерное приложение для создания учебных футбольных игр.

## Запуск

Откройте `index.html` двойным щелчком в современном браузере. Установка и интернет не требуются.

Для локального HTTP-запуска при наличии Python:

```bash
python3 -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Возможности

- четыре игровых раздела;
- пять типов заданий;
- живой предпросмотр и футбольный эпизод с ударом;
- русский и английский языки;
- загрузка фона, персонажа и GIF;
- Undo/Redo и локальный черновик;
- импорт и экспорт проекта;
- автономный HTML и облегчённый экспорт;
- адаптивный iframe-код для Genially.

Подробные требования находятся в `AI_DEVELOPMENT_SPEC.md`.
